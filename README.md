# Meet Slide Rewind

Google Meet で他の人の発表を聞いているとき、画面共有のスライドを**自動で保存**し、サイドパネルで**自由に見返せる** Chrome 拡張機能です。
発表者側の準備やサーバーは不要で、聞き手が入れるだけで動きます。

## できること

- 画面共有の映像を監視し、スライドが切り替わって約1秒落ち着いたら自動で保存
  - 箇条書きが1行ずつ出るような小さな変化も別スライドとして保存
  - 前のスライドに戻った場合は保存済みのものへジャンプ（重複保存しない）
  - アニメーション中・スライド内の動画再生中・カメラ映像は保存しない
- サイドパネルで閲覧
  - サムネイル一覧、←/→ キーで移動、クリックで別ウィンドウに拡大表示（Esc か ✕ で閉じる）
  - 「最新に追従」：見返し中は自動で止まり、「最新へ」で戻れる
  - 手動保存（📸）、一時停止、画像のダウンロード、スライド・会議ごとの削除
- 再読み込み・再参加しても、3時間以内の同じ会議には続けて保存

## インストール

```sh
npm install
npm run build
```

1. `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」で `dist/` フォルダを選ぶ
3. すでに開いている Meet タブは再読み込みする
4. Meet で画面共有を見ているときに、ツールバーの拡張アイコンを押すとサイドパネルが開く

## 仕組み

```
content script (meet.google.com)          service worker              side panel
  500ms ごとに最大タイルの <video> を      受信 → IndexedDB 保存       IndexedDB を読んで表示
  64x36 グレースケールへ縮小               重複判定                    slide-added で即時更新
  変化検出 → 静止 1 秒で確定      ──▶      slide-added を通知   ──▶
  WebP(q0.8) で送信
```

- 切り替わりの判定：前回保存した画像と比べて変化した画素の割合（0.5% 以上で変化とみなす）と、連続するサンプル同士が静止しているか
- スライドらしさの判定：同じ明るさの画素が占める割合（`flatness` ≥ 0.3）。顔や動画は判定から外れる
- 保存先：拡張機能のオリジンにある IndexedDB（`unlimitedStorage`）。1枚あたり約 10〜150KB。**7日間更新のない会議は自動で削除**

## 開発

```sh
npm test           # Vitest（検出ロジック・DB）
npm run typecheck
npm run watch      # 変更を監視してビルド
```

### E2E ハーネス

本物の Meet を使わずに、ビルド済みの拡張機能のコードをそのまま動かして確認できます。

```sh
npm run build
python3 -m http.server 8123
# http://127.0.0.1:8123/harness/index.html を開く
```

`chrome.*` をスタブに置き換え、content script・service worker・サイドパネルの3つを1ページ上で連携させます。合成した発表映像（黒画面、スライド、フェード、箇条書きの追加、前のスライドへの戻り、カーソル、動画、カメラ）を流すので、6枚が保存され、戻ったときは duplicate になれば正常です。

## 既知の制約

- **Meet の画面構成が変わると壊れる可能性**：DOM への依存は「表示中で一番大きい `<video>`」の選択だけにしていますが、Meet の大きな変更で動かなくなる可能性はあります
- **画質は共有映像に依存**：回線状況によっては細かい文字がつぶれます
- **自動では保存しにくいスライド**：全面写真のスライドや、グラデーションの背景のスライドは「スライドらしくない」と判定されることがあります。📸 で手動保存してください
- **画面共有がないとき**：一番大きいタイルが、無地の壁の前でじっとしている人のカメラ映像だと、保存されることがあります。不要なものはパネルで削除するか、一時停止してください
- **タブを裏に回したとき**：Chrome の制限でサンプリングが1秒間隔になり、検出が少し遅れます。サイドパネルを Meet タブの横に開いておく使い方を想定しています
- **記録について**：やっていることは自動スクリーンショットと同じです。記録が禁止されている会議では使わないでください。データは手元のブラウザ内だけに保存され、外部には送信しません
